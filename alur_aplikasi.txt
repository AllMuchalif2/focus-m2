TAHAP 1: INISIALISASI & ROOT SETUP (APP STARTUP)
--------------------------------------------------------------------------------
Komponen yang Terlibat:
- Root Entrypoint  : lib/main.dart (FocusApp)
- Core Theme       : lib/core/theme.dart (AppTheme)
- Core Constants   : lib/core/constants.dart (AppConstants: URL audio/video jsDelivr)
- State Management : package:provider (MultiProvider)
- Services         : 
  * AuthService           : lib/services/auth_service.dart
  * SessionRepository     : lib/data/repositories/session_repository.dart
  * MediaService          : lib/services/media_service.dart
  * TimerService          : lib/services/timer_service.dart
  * NotificationService   : lib/services/notification_service.dart
  * TimerEngine           : lib/services/timer_engine.dart
- Local Storage    : SharedPreferences (key: 'active_timer_state')
- Native Config    :
  * Android Manifest : android/app/src/main/AndroidManifest.xml (Permissions & Receivers)
  * ProGuard Rules   : android/app/proguard-rules.pro (Keep TypeToken & Firestore)
  * Build Config     : android/app/build.gradle.kts (coreLibraryDesugaring, ProGuard)

Alur Inisialisasi:
1. main() memanggil WidgetsFlutterBinding.ensureInitialized() dan Firebase.initializeApp().
2. MultiProvider menyediakan instance AuthService, SessionRepository, MediaService, dan TimerService.
3. TimerService mengikat MediaService via ChangeNotifierProxyProvider dan memanggil initialize().
4. NotificationService diinisialisasi: mengonfigurasi timezone dan meminta izin notifikasi serta exact alarms.
5. TimerService membaca SharedPreferences untuk memulihkan sesi aktif jika aplikasi sempat tertutup sebelumnya.

TAHAP 6: SESI BERJALAN & SISTEM NOTIFIKASI BACKGROUND
--------------------------------------------------------------------------------
Komponen yang Terlibat:
- Screen / UI     : lib/features/timer/timer_screen.dart (_buildControlButtons)
- Services Terkait:
  * lib/services/timer_service.dart (start(), pause(), resume(), stop())
  * lib/services/timer_engine.dart (tick(), calculateRemaining())
  * lib/services/notification_service.dart (scheduleTimerNotification(), cancelAllNotifications())
- Native Android  :
  * AlarmManager & ScheduledNotificationReceiver (AndroidManifest.xml)
  * WakelockPlus (menjaga layar tetap aktif saat sesi fokus berjalan)

Alur Sesi Berjalan:
1. User menekan tombol 'Mulai [N] Menit':
   - Validasi fallback memastikan durasi valid.
   - TimerEngine mengaktifkan status running dan menetapkan _startAt serta _endAt.
   - WakelockPlus diaktifkan.
2. Penjadwalan Notifikasi Penuh (Anti-Sleep):
   - TimerService._scheduleAllPhaseNotifications() mendaftarkan seluruh fase waktu yang akan datang ke AlarmManager sistem operasi Android dengan ID unik.
   - Jika user menekan tombol Home atau aplikasi diminimize, Alarm Android tetap membunyikan dan memunculkan notifikasi sesi tepat waktu tanpa bergantung pada Flutter ticker.
3. Pause & Resume:
   - Tombol 'Jeda': membatalkan semua alarm terjadwal, menyimpan pausedRemaining, dan menonaktifkan wakelock.
   - Tombol 'Lanjut': menghitung ulang _endAt baru dan menjadwalkan ulang seluruh sisa fase notifikasi.

TAHAP 7: INTERCEPT BACK BUTTON & DIALOG KONFIRMASI
--------------------------------------------------------------------------------
Komponen yang Terlibat:
- Screen / Widget : lib/features/timer/timer_screen.dart (PopScope & _onWillPop)
- Dialog Widget   : AlertDialog dengan 3 opsi aksi
- Services Terkait:
  * TimerService (stop)
  * MediaService (stopAmbience)
- System Platform : SystemNavigator.pop()

Alur Intercept Tombol Kembali (Back Button / Gesture):
1. Layar dibungkus PopScope(canPop: false).
2. Jika tombol Back ditekan saat sesi TIDAK aktif: aplikasi keluar atau pop secara normal.
3. Jika tombol Back ditekan saat sesi SEDANG AKTIF (running / paused), muncul dialog konfirmasi dengan 3 pilihan:
   a. 'Tetap di Sini' : Menutup dialog; timer dan audio terus berjalan normal.
   b. 'Minimize'      : Memanggil SystemNavigator.pop() sehingga aplikasi pindah ke latar belakang (background) seperti tombol Home, dengan timer dan musik tetap aktif.
   c. 'Hentikan Sesi' : Mematikan timer (timerService.stop()), mematikan audio/video (mediaService.stopAmbience()), lalu keluar dari aplikasi.

TAHAP 8: SESI SELESAI, ALARM, REFLEKSI, & PENYIMPANAN RIWAYAT
--------------------------------------------------------------------------------
Komponen yang Terlibat:
- Sheet / Widget  : lib/features/timer/widgets/finish_sheet.dart (FinishSheet)
- Data Layer      :
  * Model      : lib/data/models/session_record.dart (SessionRecord)
  * Repository : lib/data/repositories/session_repository.dart (SessionRepository)
  * Database   : Cloud Firestore (koleksi: 'users/{uid}/sessions')
- Services Terkait:
  * MediaService (playAlarm(), stopAlarm())
  * AuthService (currentUser UID)
  * TimerService (stop())
- Native / Build  : ProGuard rules menjaga TypeToken & model serialization Firestore pada APK Release.

Alur Penyelesaian:
1. Ketika timer mencapai akhir, MediaService memicu suara alarm.
2. TimerScreen secara otomatis menampilkan modal FinishSheet.
3. FinishSheet menampilkan ringkasan mode dan durasi yang telah diselesaikan serta form input catatan refleksi (maks. 280 karakter).
4. Ketika user menekan 'Simpan Sesi':
   - Dibuat objek SessionRecord dengan timestamp saat ini.
   - SessionRepository.createSession() menyimpan data ke dokumen Cloud Firestore di bawah UID user.
   - Timer direset ke idle, modal ditutup, dan alarm dimatikan.

TAHAP 10: KELUAR AKUN (LOGOUT)
--------------------------------------------------------------------------------
Komponen yang Terlibat:
- Screen / Widget : lib/features/timer/timer_screen.dart (_confirmLogout)
- Dialog Widget   : AlertDialog konfirmasi logout
- Services Terkait:
  * lib/services/timer_service.dart (stop())
  * lib/services/media_service.dart (stopAmbience())
  * lib/services/auth_service.dart (logout())
- Navigation Gate : lib/features/auth/auth_gate.dart (AuthGate)

Alur Logout:
1. User menekan icon logout di AppBar TimerScreen.
2. Muncul dialog konfirmasi 'Keluar Akun?'.
3. Jika user menekan 'Keluar':
   - timerService.stop() dipanggil untuk menghentikan sesi aktif dan membersihkan semua notifikasi alarm.
   - mediaService.stopAmbience() menghentikan audio dan membuang controller video.
   - authService.logout() mengeksekusi signOut() pada Firebase Auth.
4. Stream authStateChanges pada AuthGate mendeteksi user menjadi null, dan secara otomatis meredirect tampilan ke LoginScreen.
